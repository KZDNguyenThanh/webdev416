# KEYNITY - Mechanical Keyboard E-Commerce

E-commerce platform for mechanical keyboards and accessories.

### Prerequisites

- **Node.js:** 22.20.x
- **PostgreSQL:** 12+
- **npm:** ≥10

### Setup

```bash
# 1. Install dependencies
npm install

# 2. Create database
createdb aemeathshop

# 3. Start dev server
npm run dev
```
